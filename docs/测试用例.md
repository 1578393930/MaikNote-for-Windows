## 〇、本轮审计修复的 bug 一览

| 编号 | 严重度 | 问题 | 修复 |
|------|--------|------|------|
| BUG-A | 高 | 清空笔记正文后自动保存被跳过，磁盘残留旧内容，重开后"复活" | useAutoSave 允许空内容落盘，基线改为「改动前的值」 |
| BUG-A2 | 高 | forceSave 实际只是再次防抖；窗口卸载时挂起的防抖被取消，最后几百毫秒编辑丢失 | forceSave 绕过防抖直接落盘 |
| BUG-B | 高 | metadata.json / directories.json 损坏时被空索引静默覆盖，目录结构丢失 | Rust 侧检测非法 JSON → 先备份 `*.corrupt-<时间戳>` 再返回空索引 |
| BUG-C | 中 | 桌面卡片上一轮修复"双击选词被全文覆盖"时把整个正文区域排除，双击空白处不再复制全文 | 改为「有选区时不覆盖」：双击文字=选词复制选区，双击空白=复制全文 |
| BUG-D | 中低 | 边缘面板语言只在窗口创建时设置一次，运行中切换语言面板不跟随 | edge-prefs 增加 language 字段，边缘窗口实时应用 |
| BUG-E | 低 | edgeWidth / edgeTriggerSpan / autoSaveInterval / webdav 间隔从 localStorage 读入无钳制 | loadSettings 统一钳制（UT-SET-07 回归覆盖） |

## 四、已知限制（v1 记录在案）

1. HTTP 修改时间只有秒级精度：同秒内"同大小"的远端改动理论上可能漏检（已用文件大小辅助判定，实际场景极难触发）。
2. 删除操作不跨设备同步（防误删优先）。
3. 冲突副本按文件粒度保留，不做正文级合并。
4. 密码明文存于本机 localStorage（与现有 AI Key 存储方式一致；系统级凭据库为后续增强项）。
