MaikNote for Windows (x64)

Extract the ZIP and run MaikNote.exe. WebView2 Runtime is required.
Notes are stored in Documents\MaikNote or your custom workspace, not beside the EXE.

Portable updates: download the new portable ZIP from:
https://github.com/1578393930/MaikNote-for-Windows/releases/latest
Exit MaikNote, then replace the extracted application files.

The in-app update button downloads the signed NSIS installer. It installs the
application and does not replace this portable EXE. Use the ZIP to stay portable.
